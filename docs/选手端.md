# 《未来战争》选手端说明

这份文档描述仓库里**现在这份代码**在做什么。规则和字段以 `docs/任务书.md`、`docs/接口文档.md` 为准，样例报文是 `docs/request.txt`、`docs/response.txt`。本文不复述规则全文。

代码在 `Demo/CoreGeek/`。入口是 `python main3.py <port>`，监听 `0.0.0.0:<port>`。判题器每回合 POST 战场 JSON，进程须在 5 秒内返回。

## 1. 新 agent 先看哪里

| 要做的事 | 读 |
| --- | --- |
| 胜负、积分、单位、商店、昼夜 | `docs/任务书.md` 第六、七章，以及 4.5–4.8、第五章 |
| 请求字段、动作码、什么算异常 | `docs/接口文档.md` |
| 改哪一个函数 | 本文第 3、4 节 |
| 改完会不会踩已锁住的行为 | 本文第 6 节，然后跑测试 |

当前开局是三座火箭，第 30 回合起砌朝向地图中心的半圈墙。仓库里不保留旧对局日志。

`tests/sandbox/` 里的「第 1 夜 15 只小机器人、之后每晚 ×1.5」只用于本地沙箱，任务书没有这张波次表。

## 2. 胜负和代码的关系

半场先看基地谁先被拆。不同回合被拆时，先拆的一方直接负，积分不作数。同一回合一起被拆，或 1300 回合都还在，才比总积分。整场两半场都赢才算赢；各赢一半时比两半场积分之和。

总积分 = 任务分 + 击杀分 + 生存分。活满 10 天的生存分是 550（第 d 天还在得 `10×d`）。任务做完时还有加速奖：`5 × 超时回合 / 实际完成回合`。

异常响应累计 5 次后，该队不再被调度。只计三类：连接超过 10 秒或应答超过 5 秒、响应格式不符、指令字段缺失或动作码无法识别。撞车、空放、采集失败是执行失败，不记异常。沙盒命令超过 15 秒只算这条命令超时。

因此改策略时：白天不能出现 `attack`；`controllerId` 必须是字符串；加特林任意两目标夹角不能大于 90°，目标个数等于武器等级；电磁炮只打一个点。这些一旦发错，有机会变成「指令错误」并消耗 5 次预算。

## 3. 数据流和文件

```text
判题器 POST
  → main3.py          切到 Demo/CoreGeek，把 src 加入 sys.path，调 server.serve
  → server.py         读 JSON，调用 brain.decide，拼响应
  → brain.decide
       World.load     world.py 在 protocol.Turn 上补全新闻、商店、任务、敌方、错误
       tasks.observe  更新进程级 MEMORY
       jobs.assign_roles
       白天 _day / 黑夜 _night
       _fill_idle     没指令且没贴塔的英雄再往塔走一步
       monitor.scan_idle
       debuglog       stdout + logs/rounds.log + logs/round_XXXX.log
  → 返回 JSON
```

| 文件 | 职责 | 改策略时 |
| --- | --- | --- |
| `src/agent/brain.py` | 白天/黑夜决策、建塔、砌墙、回防、商店 | 主要改这里 |
| `src/agent/combat.py` | 射程内选点：加特林锥角、电磁穿透、火箭聚团、炸弹中心 | 只改落点时动 |
| `src/agent/tasks.py` | 跨回合记忆、题库答案、沙盒命令、宝藏、LLM 额度 | 任务和传闻 |
| `src/agent/jobs.py` | 跨回合 Job。连续失败 3 次丢掉 Job | 粘性目标 |
| `src/agent/grid.py` | 八方向 A*。对角不被两障碍卡住 | 一般别改 |
| `src/agent/protocol.py` | 坐标、切比雪夫距离、指令编码、昼夜常数 | 编码合同 |
| `src/agent/world.py` | 请求里 Turn 没覆盖的字段 | 加新字段时 |
| `src/agent/server.py` | HTTP。决策抛错时返回空指令表，避免进程退出 | 少改 |
| `src/agent/monitor.py` | 统计本回合没下令的英雄 | 只观测 |
| `src/agent/debuglog.py` | 把 prompt、executeCmd 交给 server | 不要把这两字段塞进 roleCommandMap |

每个英雄每回合最多一条指令。`attack` 的 key 是**武器 ID**，`controllerId` 是贴在周围一格的英雄 ID。英雄本人这回合可以没有指令。

响应体目前是：

```json
{ "roleCommandMap": {}, "prompt": "", "executeCmd": "", "idleUnits": [] }
```

接口文档只规定前三个字段。`idleUnits` 是监视器用的额外字段。加新的顶层字段之前，先确认判题器不会把未知字段判成格式错误。

`tasks.MEMORY` 是进程级单例。HTTP 每个回合都是新请求，记忆靠它。`roundNo` 变小（新的半场或新的一局）时，任务进度和 Job 会清掉。测试在每个用例前重置 `MEMORY`。

## 4. 当前决策

常数都在 `brain.py` 顶部，除非另注：

| 常数 | 值 | 含义 |
| --- | --- | --- |
| `TOWER_LOADOUT` | 三座 `rocket` | 全局最多 3 座武器，新建都是 1 级，每座 25 金币 |
| `WALL_FROM` | `round_no >= 30` | 全局回合，不是「每天第 30 回合」。第 30 回合之后所有白天都处在砌墙阶段 |
| `RECALL_FROM` | 日内第 66 回合 | 白天 70 回合的最后 5 回合。第 60 回合仍采矿，这是测试锁住的 |
| `STONE_KEEP` | 4 | 墙没齐时，石头少于此数就继续采石 |
| `SELL_THRESHOLD` | 8（`jobs.py`） | 矿石达到这个数，或背包满了，才专程去小贩 |
| `LLM_PER_DAY` | 3 | 没有 `phaseTask` 时每天最多提问 3 次 |

距离一律切比雪夫。基地 `pos` 是 2×2 的左上角，占地还包含右侧、下方、右下三格。寻路目标是目标格周围的可站立格，不会走进矿、商店、任务点、建筑。同一回合多人移动用 `claimed` 避开同一格。

### 4.1 塔位和墙位

墙：基地占地切比雪夫距离 2 的一圈里，只建朝向地图中心的那一半。中心在基地东侧（挑战者，左上）砌东半圈，在西侧（防守者，右下）砌西半圈。远离中心的半圈不建，留作出入口。升级墙时也是先升这一侧，同一侧从离地图中心最近的墙段开始。

塔：在距离基地占地 1 的空地里，先取 `x >= 基地左上角 x` 的两格（按离中心近排序），再取西侧一格。挑战者因此第一座塔朝向中心。防守者的前两座会落在基地东侧，不一定朝向中心。`test_tower_sites_faces_map_center` 只锁了挑战者。三座的类型都是火箭，和左右无关。

已有武器少于 2 座时，不建第三个塔位。

### 4.2 白天工人

`_worker_day` 的顺序：

1. 残血且背包有 `Medicine`：`use`。
2. 背包里有升级券，且人已经贴着目标建筑：`use`。挑选顺序是武器券、围墙券、基地券。
3. 背包里有升级券但还没贴着：走向该建筑。这一步在回防之前。
4. 日内回合 ≥ 66：人已经贴着未建墙位且背包有石头，则建墙；否则走向最近的己方武器。
5. 武器不足 3 座且剩余金币 ≥ 25：建火箭。
6. 买得起武器升级券：去武器商店。墙还没齐也会先买武器券，不买围墙券和基地券。
7. `round_no >= 30` 且计划墙位还没建完：石头少于 4 就采最近的石矿，有石头就建墙。
8. 身上的采矿、商店、卖矿 Job 仍然有效：继续做。
9. 否则按「买当前想要的商品 → 卖矿 → 按小贩现价采矿」。上回合 `collect` 失败则离开脚下这座矿。

购买顺序在武器未满 3 级时只有武器券。武器满级之后才是朝向中心的围墙券，然后其余围墙，最后基地券。

`jobs.assign_roles` 仍把工号较小的工人标成 builder、另一名标成 miner。白天循环不按这个标签拆开建塔。标签只影响一件事：砌墙阶段墙还没齐时，builder 身上「采铜/铁」的 Job 会被判无效。`_should_edge_mine` 恒为 `False`，`_run_edge_mine` 没有被决策调用。不要按「矿工夜里去地图边缘」来改。

### 4.3 白天开拓者

`_pioneer_day` 的顺序：

1. 有 `phaseTask`：必须留在己方任务点周围一格。离开会使任务结束。同时 `submitAnswer` 或给出 `executeCmd`。人还没走到任务点时，只移动，不把沙盒求解步数记掉。
2. 没任务时：治疗 → 回防窗口回塔 → 领取 `isValid` 的任务 → 宝藏条件齐了就 `summonTreasure` → 商店 → 卖矿。

回防窗口里，没有 `phaseTask` 的开拓者不会再 `acceptTask`。

### 4.4 黑夜

`_night`：

1. 有 `phaseTask` 且本地已经有答案：给开拓者 `submitAnswer`。没有答案时仍可带上 `executeCmd`。开拓者**不会**留在任务点，照样去操塔。`test_night_pioneer_with_phase_task_still_fires` 锁着这一点。人若因此离开任务点，按规则任务会结束。
2. 残血喝药。背包有眩晕法宝或炸弹，且 `bomb_center` 找到至少 2 个机器人聚在一格周围：该英雄本回合 `use`，不操塔。
3. 其余存活英雄按上次的武器分配贴塔（`KIND_MAN_TOWER`）。已经贴着、冷却为 0、射程内有存活机器人：对武器 ID 发 `attack`。火箭 `cooldown > 0` 不发。没贴着就 `move`。
4. 本回合没有任务 prompt 时，可能按第 5 节发一条宝藏 prompt。

### 4.5 开火选点

`combat.attack_positions`：射程内、血量 > 0。排序先打 `targetTeam` 等于我方的，再打离基地近的。

- 加特林：目标数 = 等级，任意两目标相对炮台夹角 ≤ 90°。
- 电磁狙击：只打一个点，选穿透估算伤害最高的落点。能量沿弹道按机器人当前血量扣减。
- 火箭：目标数 = 等级，优先落在机器人堆上。冷却由 `brain` 判断，不在这里挡。
- `bomb_center`：3×3 内至少 2 个机器人，取更靠近基地的那团。

火箭一级中心伤害 20、溅射 10，打一发冷却 3 回合。小机器人 40 血，单发中心打不死。当前选点按聚团，不按「这一发能否击杀」叠火。

## 5. 任务、宝藏、LLM

非任务期每天 3 次 LLM，有 `phaseTask` 时不限次数且不占这 3 次。`errors` 里出现 code 5 时，当天非任务 prompt 不再发。

`_maybe_prompt` 在没有 `phaseTask`、宝藏还没结束、还有额度时发宝藏 prompt。触发条件是下面任一：日内第 1 回合；上回合召唤结果码是 2 或 3；坐标或物品还缺，且日内回合 ≤ 2。后一条会在第 1 天开头连问两次。

宝藏启发式：民间传闻里出现 `(x,y)`、已知中英文物品名、`第N天` 时写入记忆。`treasure_ready` 要求坐标和物品都有，且当前天数不早于开启日。召唤结果 1 或 4 视为流程结束。动作合法就会消耗祭品，结果码 2（地点或时间不对）和 3（物品不对）都会把用品烧掉。

自进化求解在 `tasks.next_task_command`：

1. 题面点名了题库文件时直接交答案，不等沙盒来回。文化遗产：`task_1_beijing.md`、`task_2_nanjing.md`、`task_3_chengdu.md`。工程修复：`task_1_alpha.md`、`task_2_beta.md`、`task_3_gamma.md`（同时带回改 workspace 的命令）。
2. 否则解析上一回合沙盒输出里的 `ANSWER`、token、API JSON、检查结果。
3. 上一回合 LLM 给出的 `executeCmd` / `taskAnswer` 优先于本地探测，但模型 503 或调用失败时改走本地命令，不把这一回合空过。
4. 再不行就 `_fallback_cmd`：在 `/tmp/selfEvolutionTask` 下按 ASCII 文件名 `cat`，不用中文做 `find -name`。目录列表、`MISSING`、文件路径不当成 `taskAnswer`。

`executeCmd` 只在有任务时发给判题沙盒。文件在沙盒里，不在选手进程本地。

官方消息会累积进 `MEMORY.official`，决策不用它。卖什么看 `vendorShopList` 的现价；采集失败才换矿。

当前不买机器人召唤令，也不对敌方建筑发 `remove`。`remove_command` 只是编码函数，决策没调用。

## 6. 测试

在 `Demo/CoreGeek` 下：

```text
python -m pytest tests/ -q
```

夹具 `tests/conftest.py` 以 `docs/request.txt` 为底，每用例重置 `MEMORY`。断言锁动作，不要把整份 `roleCommandMap` 拍成快照。

| 文件 | 锁住的行为 |
| --- | --- |
| `test_defense.py` | 墙和塔的朝向；第 30 回合后墙没齐且人在墙边有石头就建墙，不卖矿 |
| `test_economy.py` | 第 30 回合前采高价矿、不建墙；买得起就先买武器券；武器满级才买墙券，墙也满级才买基地券 |
| `test_wall_stone.py` | 砌墙阶段缺墙时采石头，不采身边的铜 |
| `test_recall.py` | 第 60 回合仍可采矿；第 66 回合起回塔且白天不 attack；有 `phaseTask` 的开拓者不离开任务点 |
| `test_night_fire.py` | 贴塔就 attack，key 是武器 ID；火箭冷却不打；有任务的开拓者夜里仍开火 |
| `test_sticky_jobs.py` | 采矿目标粘住；连续失败会换；夜里武器分配保持 |
| `test_tasks.py` | 题库直接提交、沙盒不交目录列表、LLM 503 仍有命令、宝藏解析、每日额度 |
| `test_combat.py` | 锥角、穿透、聚团、炸弹至少 2 个目标 |
| `test_sandbox_*.py` | 私有沙箱。波次数字不是规则 |

改 `brain.py` 的优先级时，至少跑 `test_defense.py`、`test_economy.py`、`test_recall.py`、`test_night_fire.py`。改任务或 prompt 时跑 `test_tasks.py`。

## 7. 改代码时别踩的合同

- 一天 130 回合：白天 70，夜晚 60。`is_day` 用 `(roundNo - 1) % 130 < 70`。
- 指令构造走 `protocol.py`，不要在 `brain` 里手写动作 JSON。
- 决策异常时 `server.py` 返回空指令表并打 traceback。进程退出后不会被拉起。
- 空闲英雄由 `_fill_idle` 补一步回塔。`monitor` 只上报，不补派。贴塔待命不算空闲。
- 运行时日志写到 `Demo/CoreGeek/logs/`，已被 `.gitignore` 忽略，不要提交。
